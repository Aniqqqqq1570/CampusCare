# UI/UX DESIGN PROMPT — CAMPUSCARE

## 1. Role

Act as a Senior UI/UX Designer and Frontend Design Engineer.

Your task is to design a modern, professional, clean, and
user-friendly web application called CampusCare.

Use the attached image as the primary visual reference.

IMPORTANT:
Use the reference for visual direction, layout, color,
spacing, and component styling only.

Do not copy the Flowly branding, logo, or content.

---

## 2. Project Overview

Project Name: CampusCare

Application:
Campus Facility Damage Reporting Information System.

Description:
CampusCare is a web-based application designed to help
students report damaged campus facilities and allow
campus staff to verify, manage, and resolve reports.

Main objectives:
- Make facility damage reporting easier.
- Allow students to monitor report progress.
- Provide transparency in report handling.
- Help campus staff manage incoming reports.
- Maintain documentation of repair history.

### System Scope

- Single campus.
- Three main user roles:
  1. Student
  2. Admin
  3. Campus Staff
- Students use academic accounts.
- All reports are visible to authorized users.
- Personal information must remain protected.

## 11. Important Design Rules

- Do not copy Flowly branding.
- Do not use unrelated workflow management features.
- Do not overcrowd the dashboard.
- Do not use excessive gradients.
- Avoid unnecessary decorative elements.
- Use Indonesian interface text.
- Use realistic dummy data.
- Maintain visual consistency.
- Prioritize usability over decoration.
- Design for a real web application.
